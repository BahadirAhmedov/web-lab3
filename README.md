# web-lab3

Веб-версия игры 2048 на чистом HTML, CSS и JavaScript

https://cute-beijinho-77bcfb.netlify.app

## Управление

- **Компьютер** - стрелки на клавиатуре
- **Телефон и планшет** - кнопки со стрелками под игровым полем
- **Отменить ход** - вернуть последний ход
- **Начать заново** - новая игра
- **Лидеры** - таблица рекордов

Одинаковые плитки при столкновении складываются. Игра заканчивается, когда ходов больше нет - тогда можно ввести имя и сохранить результат
